> **Authentic detail:** the isotipo pairs a **blue "e"** with an **orange parenthesis** — that orange bracket is the brand's signature. (Earlier drafts of this system used a blue bracket; the real vectors corrected it.) The standalone parenthesis device may still be set in any brand color (azul / naranjo / verde / blanco) per the manual.

**Logo rules:** keep the "e" and parenthesis together; never recolor outside palette, rotate, deform, or add effects. Min size ~20px wide (isotipo). Place top-left (preferred) or bottom-right. Scale the standalone parenthesis large (≈150–250% of the longest side), showing both corners or keeping the left.

**Wordmark "entel)":** the full **horizontal lockup** (isotipo "e)" + "entel" wordmark) was extracted as real vectors from `uploads/manual marca logos.pdf` → `entel-logo-horizontal-color.svg` / `-blanco.svg` (+ 2800px PNGs). This is the primary logo and is used in the UI-kit headers. (A vertical lockup also exists in the source but isn't shipped — it's an "exceptional use" variant.)
